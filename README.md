# Shizuku

A single-player, Mudae-inspired character gacha. Roll a card, claim it before the
window closes, and build a collection of kakigori. Everything runs in the browser
— no backend, no accounts. Progress is saved to `localStorage` under
`shizuku.state.v1`.

## Run it

```bash
npm install
npm run dev
```

| script | what it does |
| --- | --- |
| `npm run dev` | Vite dev server with HMR |
| `npm run build` | type-check (`tsc -b`) then production build |
| `npm run lint` | Oxlint |
| `npm run preview` | serve the production build |

## How it is put together

- `src/engine/game.ts` — the game itself: rolls, the claim window and its cooldown,
  the credit/shard economy, the once-a-second tick. Pure functions over
  `GameState`; the UI never decides a rule.
- `src/engine/store.ts` — the React binding: load and hydrate, tick every second,
  save on change, undo, flash messages.
- `src/engine/roster*.ts`, `src/engine/tiers.ts` — the card roster and the tier table.
- `public/roster-extra.json`, `public/roster-images.json` — the extra pool and its
  image map. Kept out of the JS bundle and fetched at boot by `loadExtraRoster()`
  and `loadImageMap()`.
- `src/components/` — screens and panels. `src/styles.css` and `src/icons.css` hold
  all styling; icons are hand-authored SVG, no icon library.

## Dev fixtures

`?state=empty`, `?state=mid`, `?state=late` — dev server only. They build a sample
save in memory and never read or write `localStorage`, so the unlocked crate, the
empty plinth or a 12/12 basin are reachable without touching a real save. A
`fixture · <name>` chip in the corner marks the page.

## Layout previews

`?preview=v3`, `?preview=v4`, `?preview=icons` mount the code-split layout studies
instead of the app.

## Data and artwork

Card images are fetched at runtime from AniList (`graphql.anilist.co`) and Jikan
(`api.jikan.moe`) and cached by the browser. Character names and artwork belong to
their respective rights holders; nothing here is redistributed as an asset. The
roster data in `public/` is generated by `scripts/build-roster.mjs`.
